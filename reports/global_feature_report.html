Interpretation

Permutation importance ranks how much each harmonized field and the region context move within-source discrimination; sampled source-conditioned effect curves on the web governance page show fitted direction. Small-cohort metrics are descriptive and uncertain, not league tables.

Educational-use notice. LimitIQ is an educational portfolio demonstration using public and synthetic data. It is not a production credit-decision system and must not be used to make real lending decisions.
