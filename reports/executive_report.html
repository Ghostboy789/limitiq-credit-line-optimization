Governance boundary

The source is Taiwan 2005, the split is random within source, and no public record observes affordability or response to a line increase. Scores are model estimates; demo affordability, exposure, loss, contribution, monitoring and experiment outputs are deterministic simulations. Real use requires representative local data, verified affordability, independent validation, approved experiments and monitored rollback.

Educational-use notice. LimitIQ is an educational portfolio demonstration using public and synthetic data. It is not a production credit-decision system and must not be used to make real lending decisions.
